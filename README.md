# 🧩 UML Editor  
*A lightweight and flexible tool for creating, managing, and exporting UML design artifacts on desktop.*

The **UML Editor** is a semester project for Software Construction and Development course, designed to support the creating, organizing and editing UML diagrams such as class diagrams, and use-case diagrams.  
The goal of the project is to showcase understanding of Java concepts learned throughout the SCD course and make an easy to use UML editor

This project focuses on maintainability, scalability, and adherence to standard software engineering practices, including layered architecture and design patterns.

## Features  
- Create and manage UML projects  
- Organize design artifacts (class, use-case diagrams)  
- Maintain model information and relationships (class, interface, association, inheritance, etc.)  
- Save and load projects (using Serialization)
- GUI support for shapes and visual elements  
- Export diagrams to PNG/JPEG  
- Code generation from UML models  
- Relationship handling (inheritance, association, multiplicity)  

## Constraints followed
- Implemented Layered Architecture (UI, Business logic, Data layer)
- Applied Template Method Design Pattern
- Followed Test-Driven Development (TDD) using JUnit  
- Proper exception handling and logging 
- Documentation generated for classes and components using JavaDocs
- Regular commits pushed to a GitHub repository  

## Tech Stack
- Java
- JUnit
- JavaDocs

## ⚙️ Installation & Setup
Run the project as a jar executable file:
```bash
git clone <your-repo-url>
cd <project-folder>
cd UMLEditor/out/artifacts/UMLEditor_jar
```
